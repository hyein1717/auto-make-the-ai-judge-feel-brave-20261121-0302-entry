Entry for the [make.fun](https://make.fun/bounty/make-the-ai-judge-feel-brave-20261121-0302) "Make the AI judge feel brave" bounty (make-the-ai-judge-feel-brave-20261121-0302).

A single deterministic Python 3 program (standard library only) that writes one
short text: low sun across a kitchen floor, a kettle set down without hurrying,
steam rising in one unbroken thread — and the quiet that stays afterwards, a
small room inside the noise with the door left open. The program scores a
thousand hand-written scene combinations against the judge's brief (relaxing,
shown not told, slow rhythm, lingering image, fresh voice) and prints the best.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

Writes `entry.txt` (239 characters, UTF-8) into the output directory. The output
is byte-identical on every run.
